# hxyfront-62013 木结构榫卯构件测绘

源提示词编号：8

开发一个古建筑木结构榫卯构件测绘前端项目，测绘人员可以录入建筑名称、构件编号、木材种类、榫卯类型、截面尺寸、病害位置、变形情况和修缮建议。页面需要有构件清单、榫卯类型筛选、尺寸记录表、病害标记图和单栋建筑的构件关系视图。

## 技术栈

React + Vite + TypeScript

## 本地运行

```bash
npm install
npm run dev
```

开发端口：62013

## 修缮版本闭环规则

1. **唯一编号**：同一建筑内构件编号唯一；编号相同视为同一构件的再次测绘。
2. **入库闸门**：木材、榫卯类型、截面尺寸、病害位置、变形情况缺一不可；截面尺寸非正数、病害坐标越界（沿长超出构件长度，或截面高度比超出 0~1）一律拒收。拒收只写入拒收日志，**不产生新版本、不覆盖旧测绘**。
3. **版本链**：每次有效测绘追加 v1、v2……旧版本永久保留；修缮建议只由对应测绘版本生成。
4. **建议失效**：重新测绘一旦通过校验，旧建议立即变为“已失效”（记录保留可查），构件清单、施工清单只引用最新有效版本的建议。
5. **同批关系视图**：构件关系视图以测绘批次为锚，对每个构件统一取“不晚于该批次”的最大版本，保证全图为同批快照；切换旧批次时与现行版本不一致的构件标记为“过期版本混用”，缺失构件单独标记。
6. **施工清单拦截**：只有锚定最新批次且全图均为同批有效版本时才能生成/导出施工清单；任何过期版本或缺失构件都会阻断，避免错误构件进入施工。

数据保存在浏览器 `localStorage`（键 `timber-survey-closed-loop-v1`），页面右上角可恢复示例数据。
